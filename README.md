# 오로라 에스테이트 — 4인 온라인 보드게임

부루마블의 이름/이미지/맵을 복제하지 않고 만든 오리지널 4인용 웹 보드게임입니다.

## 포함 기능
- 2~4명 실시간 온라인 방
- 방 코드로 입장
- 실시간 플레이어 위치/돈/소유 토지 표시
- 2개의 주사위를 굴려 이동
- 토지 구매 및 통행료
- 출발 통과 시 보너스
- 이벤트/세금/특별 이동 칸
- 파산 처리
- PC/모바일 반응형 화면

## 실행 방법

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 열고 닉네임과 방 코드를 입력합니다.

같은 컴퓨터에서 테스트하려면 브라우저 탭을 여러 개 열 수 있습니다.
친구와 인터넷으로 플레이하려면 이 서버를 인터넷에서 접속 가능한 서버에 배포한 뒤,
친구들에게 서버 주소를 공유하면 됩니다.

### 클라우드 배포
이 프로젝트는 일반적인 Node.js 웹 서비스에 올릴 수 있습니다.
`npm install` 후 `npm start`로 실행하면 됩니다.
PORT 환경변수를 서버가 제공하는 포트에 맞춰 설정할 수 있습니다.

## 게임 규칙
- 시작 자금: 10,000원
- 자신의 차례에 주사위 2개를 굴립니다.
- 빈 토지는 구매할 수 있습니다.
- 다른 플레이어의 토지에 도착하면 통행료를 냅니다.
- 출발 칸을 지나면 1,000원을 받습니다.
- 세금/이벤트/특별 이동 칸이 있습니다.
- 돈이 0원이 되면 파산하며 소유 토지가 해제됩니다.
- 마지막까지 파산하지 않은 플레이어가 승리합니다.
